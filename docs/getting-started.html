Começar

Suba o servidor, configure as variáveis obrigatórias e integre o SDK Go na sua aplicação.

Clone e ambiente

Copie o exemplo de env e preencha as chaves. O servidor falha no startup se faltar alguma.

shell 
cp .env_example .env

# obrigatórias
SECRET_KEY=...
SERVICE_CLIENT_AT=...
SDK_CLIENT_AT=...

# persistência
REPOSITORY_TYPE=mongodb   # ou jsonfile
MONGODB_URI=mongodb://admin:password@localhost:27017
MONGODB_NAME=featureflag

Suba o stack

Com Docker você sobe app + MongoDB. Sem Docker: go run ./cmd (porta :3000).

shell 
docker-compose up -d
# http://localhost:3000

Instale o SDK

shell 
go get -u github.com/IsaacDSC/featureflag

Crie uma flag e leia no SDK

curl
curl -X PATCH http://localhost:3000/featureflag/checkout \
  -H "Content-Type: application/json" \
  -d '{"flag_name":"checkout_v2","description":"novo checkout","active":true}'
Go
ff := featureflag.NewFeatureFlagSDK("http://localhost:3000", "checkout")
go ff.Listenner(ctx)

if ff.GetFeatureFlag("checkout_v2").Val() {
  // feature ligada
}

Autenticação

Tokens estáticos no header Authorization: SERVICE_CLIENT_AT para escrita/admin e SDK_CLIENT_AT para rotas /sdk/{key}.
