Feature Flags

Modelo AP: o SDK cacheia flags do project e atualiza por polling. Mudanças chegam no próximo ciclo de refresh — não há server-push.

Escopo por project. Rotas usam /featureflag/{project}/.... O project deve casar com ^[a-z0-9][a-z0-9-]{0,63}$.

Rotas

Método & path Descrição Auth
PATCH /featureflag/{project} Cria/atualiza uma flag —
GET /featureflag/{project}/all Lista todas as flags do project —
GET /featureflag/{project}/{key} Busca uma flag (session_id opcional) SERVICE_CLIENT
GET /featureflag/{project}/sdk/{key} Leitura via SDK SDK_CLIENT
DELETE /featureflag/{project}/{key} Remove uma flag SERVICE_CLIENT

Circuit breaker (on/off)

curl
curl -X PATCH http://localhost:3000/featureflag/checkout \
  -H "Content-Type: application/json" \
  -d '{
    "flag_name": "checkout_v2",
    "description": "novo checkout",
    "active": true
  }'

Percentual (A/B)

50% das avaliações ativas, 50% inativas — útil para rollout gradual.

curl
curl -X PATCH http://localhost:3000/featureflag/checkout \
  -H "Content-Type: application/json" \
  -d '{
    "flag_name": "rollout_50",
    "active": true,
    "strategy": { "percent": 50 }
  }'

Session ID

Só sessões listadas recebem a flag como ativa.

curl
curl -X PATCH http://localhost:3000/featureflag/checkout \
  -H "Content-Type: application/json" \
  -d '{
    "flag_name": "beta_users",
    "active": true,
    "strategy": {
      "session_id": ["34eec623-c9f2-494e-bf66-57a85139fd69"]
    }
  }'

Uso no SDK

Instancie com host + project. Listenner bloqueia até o contexto cancelar — rode em goroutine. WithEventualConsistency define o intervalo de refresh.

Go
ff := featureflag.NewFeatureFlagSDK("http://localhost:3000", "checkout").
  WithEventualConsistency(30 * time.Second)

go func() {
  if _, err := ff.Listenner(ctx); err != nil {
    panic(err)
  }
}()

on := ff.GetFeatureFlag("checkout_v2").WithDefault(false)
pct, err := ff.GetFeatureFlag("rollout_50").Err()
beta, _ := ff.GetFeatureFlag("beta_users", sessionID).Err()

Listar / buscar / remover

shell
# listar
curl http://localhost:3000/featureflag/checkout/all

# buscar (SERVICE_CLIENT)
curl http://localhost:3000/featureflag/checkout/checkout_v2 \
  -H "Authorization: service"

# SDK route
curl http://localhost:3000/featureflag/checkout/sdk/rollout_50 \
  -H "Authorization: sdk"

# remover
curl -X DELETE http://localhost:3000/featureflag/checkout/beta_users \
  -H "Authorization: service"
