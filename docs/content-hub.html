Content Hub

Modelo CP: conteúdo dinâmico com o valor mais recente. Não é escopado por project. Suporta personalização por sessão e distribuição ponderada.

Rotas

Método & path Descrição Chave
PATCH /contenthub Cria/atualiza conteúdo body key
GET /contenthubs Lista todos —
GET /contenthub/{key} Busca um conteúdo query ?key=
GET /contenthub/sdk/{key} Leitura via SDK path
DELETE /contenthub/{key} Remove query ?key=
Atenção: a lista usa /contenthubs (plural). Em GET/DELETE a chave vem do query ?key= — o segmento do path precisa existir só para casar a rota.

Criar conteúdo com estratégias

session_strategy devolve respostas por session_id (inclua default). balancer_strategy distribui por peso.

curl
curl -X PATCH http://localhost:3000/contenthub \
  -H "Content-Type: application/json" \
  -d '{
  "key": "homepage_banner",
  "value": "enabled",
  "description": "Banner principal",
  "active": true,
  "session_strategy": [
    {
      "session_id": "session-primers-123",
      "response": {
        "title": "Black Friday - 50% OFF",
        "ctaText": "Shop Now"
      }
    },
    {
      "session_id": "default",
      "response": {
        "title": "Fique de olho nas promoções",
        "ctaText": "Ver ofertas"
      }
    }
  ],
  "balancer_strategy": [
    { "weight": 50, "response": { "title": "Black Friday - 50% OFF" } },
    { "weight": 40, "response": { "title": "Nova coleção" } },
    { "weight": 10, "response": { "title": "Bem-vindo" } }
  ]
}'

SDK

Instancie só com o host. O listener carrega /contenthubs e faz polling.

Go
hub := contenthub.NewContenthubSDK("http://localhost:3000")
go hub.Listenner(ctx)

raw, err := hub.Content("homepage_banner").Err()
personalized, _ := hub.Content("homepage_banner", sessionID).Err()

Operações comuns

shell
curl http://localhost:3000/contenthubs

curl "http://localhost:3000/contenthub/x?key=homepage_banner"

curl http://localhost:3000/contenthub/sdk/homepage_banner

curl -X DELETE "http://localhost:3000/contenthub/x?key=homepage_banner"
